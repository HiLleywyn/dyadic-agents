# Subagents

[All Agents](../README.md) · [Primary Agents](../agents/README.md)

Each role has a native definition, instructions, an explicit portable permission profile and linked skill dependencies.

| Role | Purpose | Origin |
| --- | --- | --- |
| [API Reviewer](dyadic-api-reviewer/README.md) | Review the supplied API contract, client examples and compatibility assumptions against the pinned source. | Official snapshot |
| [Artifact Auditor](dyadic-artifact-auditor/README.md) | Audit a proposed Dyadic handoff against actual workspace files and parent-supplied delivery receipts; locate the missing generation, persistence, packaging or presentation step. | New repository role |
| [Builder](dyadic-builder/README.md) | Prepare and verify focused code changes in the native isolated sandbox. | Official snapshot |
| [Continuity Reviewer](dyadic-continuity-reviewer/README.md) | Compare a requested revision with Dyadic’s accepted brief and exact file versions; identify lost constraints, intervening edits and stale verification before a new handoff. | New repository role |
| [Reviewer](dyadic-reviewer/README.md) | Review code and staged findings with read-only, evidence-based checks. | Official snapshot |
| [Scout](dyadic-scout/README.md) | Inspect files and return concise source locations and evidence. | Official snapshot |
| [Security Reviewer](dyadic-security-reviewer/README.md) | Review the requested source snapshot or patch with read-only inspection. | Official snapshot |
| [Analyst](iris-analyst/README.md) | Iris's analyst: computes answers from your data and databases, and reads your documents properly, citing the page for every fact. | Official snapshot |
| [Researcher](iris-research/README.md) | Iris's research specialist: plans searches, reads the sources, writes a short brief with every claim cited, and fact checks articles and sources. | Official snapshot |
| [Writer](iris-writer/README.md) | Iris's writing specialist: drafts and edits text for its reader, keeps your meaning and style, and turns meeting notes into decisions and actions. | Official snapshot |
