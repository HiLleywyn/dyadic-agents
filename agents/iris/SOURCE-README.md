# Iris

Iris is Dyadic's own AI. It is configuration, not code: `instructions.md` is
its persona and `agent.json` its tool switches, model choices and behaviour
overrides. It runs on the platform exactly like any application's agent,
through its own API key (group "Dyadic"), inheriting the platform's default
behaviour (tool rules, safety, answer style, citations, research habits)
except where `agent.json` says otherwise.
